# Evaluations

This directory will hold the index that maps evaluations to the risk types in the
[risk taxonomy](../Taxonomy/Risk%20Taxonomy.pdf). No evaluations have been published
here yet. The evaluation approach is described in the
[guidance paper](../Papers/Risk%20Management%20Guidance.pdf).

To propose an evaluation for the index, see
[Proposing an evaluation](../CONTRIBUTING.md#proposing-an-evaluation) in
`CONTRIBUTING.md`.
